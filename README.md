# BU Housing & Campus Decision Tool

帮助 BU 学生比较宿舍：把宿舍信息、教学楼位置和自己常去的教学楼结合起来，看每个宿舍到这些教学楼有多远。

## 为什么做

- 宿舍信息分散在官网、小红书、论坛等地方，缺少直观对比。
- 选宿舍、选课时缺乏对校园空间的整体感知（宿舍离教学楼多远？15 分钟够不够跨校区？）。

## 技术

- HTML / CSS / 原生 JavaScript
- Leaflet（地图）
- `data.json`（宿舍和教学楼数据）
- Haversine 公式（根据经纬度算直线距离）

## 文件说明

| 文件 | 职责 |
| --- | --- |
| `index.html` | 页面骨架：标题、教学楼选择区、结果区、地图容器 |
| `style.css` | 页面布局和样式 |
| `data.json` | 只保存宿舍和教学楼数据 |
| `map.js` | 初始化地图、添加 marker |
| `distance.js` | 只负责距离计算 |
| `app.js` | 主逻辑：读数据、读用户选择、计算、排序、更新页面 |

## 如何运行

在项目文件夹里启动一个本地服务器：

```bash
python3 -m http.server 8000
```

然后在浏览器打开 http://localhost:8000
